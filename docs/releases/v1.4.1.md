# AlipanBuddy v1.4.1

v1.4.0 之后的修补版本：一个界面缺陷、一种被误删的 Linux 分发格式，以及持续集成的输入缺失。

## 修复

- **目录树在高窗口下底部留白**。Arco 的虚拟列表只渲染 `buffer × 3` 行，而 `buffer` 默认为 10，
  即约 960px（32px 一行）；窗口再高，下面就是一片空白，看起来像目录没有加载完。现在所有目录树
  （网盘左侧树、快捷方式、各个弹窗与插件里的文件夹选择树）都按可视高度计算 `buffer`
  （`src/utils/arcotree.ts` 的 `treeVirtualListProps`）。
- **持续集成**。新加的 CI 工作流在两个任务上都失败，原因相同：缺少只有开发机上才有的生成物。
  类型检查需要 `src/secrets.generated.ts`，tauri 的构建脚本会在编译前校验 aria2c sidecar 与
  `dist` 目录。工作流现在先生成这些输入；另加 `pretypecheck` 钩子，新克隆的仓库也能直接
  `pnpm run typecheck`。

## 找回

- **Linux tar.gz 分发**。v1.4.0 的瘦身把 tar 包连同 `install.sh` 一起去掉了，但它是不依赖发行版包管理器的
  唯一安装方式。现已恢复：与 deb / rpm 出自同一份 FHS 目录树，解压后 `./install.sh`（或 `--user`）安装，
  `--uninstall` 卸载。

## 保持不变

- 「分享」页里的资源站点继续在独立窗口中打开。评估过在右侧面板内嵌：iframe 无法上报跨域导航、且多数站点
  禁止被嵌入；真正的内嵌 WebView 需要 Tauri 尚不稳定的多 WebView 特性并持续同步几何位置。
  收益是外观上的，代价是长期的，因此不做。
