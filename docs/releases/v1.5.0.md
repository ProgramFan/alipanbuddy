# AlipanBuddy v1.5.0

v1.4.1 之后的版本：修好插件页的留白，把资源站点交给系统浏览器，去掉两个不再需要的页面。

## 修复

- **插件页面右侧留白**。「空目录扫描」「扫描重复文件」「扫描大文件」「扫描违规文件」「网盘相册间复制」
  五个页面都用「窗口高度 − 常量」计算列表高度，窗口一高（或记录的窗口高度过时）下面就是一片空白，列表底部
  还拖着一条多余的横向滚动条。现在整页用 flex 布局：步骤卡片定高，工具卡片占满剩余空间，列表在卡片内滚动。
  两个虚拟目录树仍需要像素高度（Arco 按高度计算 `buffer`），改为用 ResizeObserver 量所在容器
  （`src/utils/elementsize.ts` 的 `useElementHeight`），不再从窗口高度减常量。

## 变更

- **资源网站在系统浏览器中打开**。v1.4.1 说过资源站点继续留在独立窗口里；实际用下来那个第二个 WebView 在
  Linux 上从来不稳定，于是不再保留：站点列表照旧，点开一律交给系统默认浏览器。独立窗口连同它的三个 Tauri
  命令、`site` 窗口标签与能力授权、导航事件、站点条目的 `external` 标记以及分享页里的浏览器工具栏一起删除，
  登录窗口成为唯一的浏览器窗口。代价是在站点里点击阿里云盘分享链接不再自动弹出导入框；复制链接后主窗口
  仍会识别剪贴板。
- **「资源网站」移到「分享」侧栏末尾**，「分享」页默认打开「我的导入」，Ctrl+Tab 的顺序随之调整。

## 移除

- **视频文件洗码**（插件页）。连同菜单项、i18n 键、图标映射，以及只有它在用的文件追加写入命令
  （`fs_append_bytes` 与 `fsx::append_bytes`）。插件页默认打开「文件加密解密」。
- **订阅推荐**（分享页）。连同它的 store、加载逻辑、两个推荐接口封装、从 gitee 拉取分类列表的请求和退出登录时的重置。

## 数字

按 `pnpm run metrics`，与 v1.4.1 相比：渲染层 48942 → 48085 行，Rust 4130 → 4058 行，i18n 键 727 → 725，
npm 依赖仍为 27 个；`knip` 与 `cargo check` 均无告警。
