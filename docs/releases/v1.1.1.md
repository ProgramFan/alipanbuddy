# AlipanBuddy v1.1.1

Linux 打包修正版本。

## 打包与发布

- **deb / rpm 采用与 tar 包一致的 FHS 目录结构**：主程序与自带的 aria2c 安装到
  `/usr/lib/alipanbuddy/`，`/usr/bin/alipanbuddy` 为符号链接 —— 不再向 `/usr/bin`
  安装 aria2c，避免与系统 aria2 软件包冲突。
  - deb 声明 webkit2gtk-4.1 / gtk3 / appindicator 依赖；rpm 由 rpmbuild 自动生成共享库依赖。
- **移除 macOS 与 AppImage 构建**：发行版仅提供 Windows 安装器（x64 / ARM64）与
  Linux 的 deb / rpm / tar 包（x86_64 / aarch64）。macOS 可自行 `pnpm run build:mac` 构建。
- 三种 Linux 包由同一脚本（`scripts/build-linux-packages.sh`）从同一份 staging 目录生成，
  本地 `pnpm run build:linux` 与 CI 完全一致。

其余功能与 v1.1.0 相同（Material Design 界面重构、Linux 稳定性修复等，详见 v1.1.0 发行说明）。
