# BoxPlayer v5.0.18

## 书籍与阅读

- 新增漫画阅读模式，支持 CBZ、CBR、CB7、CBT 等常见漫画格式，可选择单页、双页、连续滚动与从右到左阅读。
- 同一本书的 EPUB、MOBI、AZW3、PDF 等格式会自动归并为一个作品，并可在作品内切换版本。
- 书籍库可根据清洗后的文件名从 Google Books 补全封面、作者与简介；扫描过程增加请求串行化与限速，降低云盘及元数据服务的 429 风险。
- 修复云端 EPUB 元数据补全、阅读器初始化卡住，以及网络下载已返回但阅读器持续加载的问题。
- 修复独立阅读器窗口的阅读进度保存与恢复；退出后再次打开会回到上次位置。
- 单页阅读模式保持固定书页布局，优化章节页码、总进度、底部进度条的计算与显示。

## 播放与字幕

- 扫描媒体库时自动关联同目录字幕，并将字幕选择集中到播放器控制区。
- 字幕下载、预览和播放会使用文件所属网盘账号的请求上下文，修复多账号与 115 等网盘下字幕无法加载的问题。
- 内置网页播放器、内置 MPV 与自定义播放器统一支持字幕扫描范围设置。
- 优化 Quark 下载任务串行处理，降低高频请求导致的失败。

## 应用体验

- 设置中心新增快速搜索，结果以弹出列表展示，便于直接定位设置项。
- 注册 Windows、macOS 的视频、音频与电子书文件关联；从系统双击文件可直接在 BoxPlayer 中打开。

## 说明

- 本版本基于 `v5.0.17` 之后的 36 个提交构建。
- Google Books 元数据补全需要在本地 `.env.local` 配置 `GOOGLE_BOOKS_API_TOKEN`。
