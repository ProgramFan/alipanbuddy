# AlipanBuddy v1.2.0

界面细节打磨、窗口与布局状态记忆，以及 Linux 包依赖声明修正。

## 界面

- 网盘页左侧「文件 / 快捷」切换器真正居中：侧栏内容此前固定按 300px 宽度排版、再用负边距往左
  拉回，在 240px 的分栏里既被右侧裁掉又整体偏移；现在直接按分栏实际宽度排版，负边距一并移除。
- 「快捷」模式下的标记（标签）行改为整行居中，与上方的切换器对齐。
- 顺带修复：快捷文件行的「删除」按钮此前被裁在可视区之外，现在贴齐侧栏右边缘。

## 窗口与布局记忆

- 记住主窗口的大小、位置与最大化状态（写入 `config.json`）：
  - 移动窗口同样会记录；关闭窗口与托盘退出时立即写盘，不再依赖防抖计时器；
  - 恢复位置前会校验窗口左上角仍落在已连接的显示器上，拔掉外接屏后不会把窗口丢到屏幕外；
  - 最大化时保留还原尺寸，只记录最大化标记，下次启动直接以最大化打开。
- 记住网盘页的分栏位置：拖动分隔线后写入本地存储，重启、或收起再展开侧栏都会回到上次的宽度
  （此前每次切换侧栏都会重置回 240px）。

## Linux 打包

- deb 的依赖改为用 `dpkg-shlibdeps` 从构建产物推导，补齐了此前缺失的 `libssl3`（reqwest 走
  native-tls / OpenSSL）、`libsoup-3.0-0`、`libjavascriptcoregtk-4.1-0`、`libglib2.0-0` 等；
  工具不可用时回退到同一份手工维护的列表。
- rpm 改为显式声明主程序 `NEEDED` 段里的 soname 依赖 —— CI 在 Ubuntu 上打 rpm，而那里的
  rpmbuild 没有 ELF 依赖生成器，此前产出的 rpm 实际上不带任何依赖声明。
- 两种包都手工声明托盘所需的 appindicator（它通过 `dlopen` 加载，不会出现在 `NEEDED` 中），
  rpm 使用 `(libayatana-appindicator3.so.1 or libappindicator3.so.1)` 富依赖以同时适配
  Fedora / openSUSE；两者另外补上 `hicolor-icon-theme`。

自带的 aria2c 为静态链接，不引入任何额外依赖；目录结构与 v1.1.1 一致
（`/usr/lib/alipanbuddy/` + `/usr/bin/alipanbuddy` 符号链接）。
