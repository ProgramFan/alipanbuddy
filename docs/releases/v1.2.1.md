# AlipanBuddy v1.2.1

Linux tar 包目录结构调整。

## 打包

- tar 包不再包含 `usr/` 这一层：解压后顶层直接是 `bin/`、`lib/alipanbuddy/`、`share/`
  与 `install.sh`，本身就是一份可直接使用的 FHS 前缀目录（把这三个目录 `cp -a` 到
  `/usr/local` 或任意前缀下同样可用）。
- `install.sh` 相应改为从 `bin/ lib/ share/` 读取，用法与参数不变
  （`--user`、`--prefix DIR`、`--uninstall`）。
- deb / rpm 的安装路径不变，仍是 `/usr/lib/alipanbuddy/` 加上 `/usr/bin/alipanbuddy`
  符号链接；三种包依旧由同一份 staging 逻辑生成，只是包内多一层 `usr/` 前缀。

其余功能与 v1.2.0 相同（网盘侧栏居中、窗口与分栏位置记忆、Linux 依赖声明修正，
详见 v1.2.0 发行说明）。
