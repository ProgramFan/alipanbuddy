# AlipanBuddy v1.1.0

界面全面重做 + Linux 稳定性修复的版本。

## 界面（Material Design 重构）

- 以 Material Design 3 为蓝本重做全部界面：统一的形状比例（4/8/12/16px 圆角）、分层表面色、
  发丝线分隔、标准海拔阴影；移除了旧版的大圆角玻璃悬浮卡片、霓虹渐变与背景模糊。
- 亮色 / 暗色主题共用同一套品牌蓝强调色，暗色不再使用青色霓虹。
- 所有页面统一为「着色侧栏 + 画布内容区」布局；网盘页与其他页完全一致。
- 全部侧栏均可拖拽调宽（网盘页原有的分栏拖拽也已对齐分隔线）。
- 新建 / 上传等操作菜单完整展开，不再出现内部滚动条；细化了树形滚动条、右键菜单、
  分段控件、强调色标签（红色仅用于危险警告）等大量细节。

## 修复

- Linux：点击分享站点 / 登录窗口可能卡死整个应用 —— 建窗命令改为异步，避免 GTK 主循环死锁，
  并默认禁用 webkit2gtk 的 DMA-BUF 渲染器（可用环境变量覆盖）。
- 面板高度计算错误导致的网盘左侧菜单被裁切与多余滚动条。
- 设置页字体颜色失效（引用了不存在的 CSS 变量）与永不生效的暗色选择器。
- 构建脚本缺失 semver 依赖、`scripts/prepare-sidecars.mjs` 被 gitignore 误排除导致 CI 必败的问题。

## 发布与安装

- Release 流程改为推送 `v<x>.<y>.<z>` 标签自动触发。
- 新增 Linux FHS tar 包（`alipanbuddy-*-linux-<arch>.tar.gz`）：内含 `usr/` 目录树、桌面项与图标，
  解压后 `sudo ./install.sh` 即可作为桌面应用安装（支持 `--user`、`--prefix`、`--uninstall`）。
- 发行版不内置任何凭据：请在「设置 → 账户设置 → OpenAPI 授权」填入自己在
  [阿里云盘开放平台](https://www.aliyundrive.com/developer) 申请的 client id / secret。
