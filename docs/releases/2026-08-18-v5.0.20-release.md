# BoxPlayer v5.0.20 Release Notes

发布日期 / Release date: 2026-08-18

## 中文

### 启动与性能

- 应用窗口优先显示，网盘账号资料、传输记录、缓存统计、WebDAV 和更新检查转为后台初始化，避免任一网盘请求阻塞进入文件列表。
- 上传、下载 Worker 改为按需创建；已排队的消息会在 Worker 就绪后自动补发。
- 重型页面与预览组件改为按需加载，减少首次启动的前端负担。
- 百度网盘资料和目录请求增加超时保护，异常账号不会长期阻塞启动流程。

### 网盘浏览、搜索与分页

- 文件列表触底续页与视频、音乐、书籍扫描现在共用同一套分页状态机：统一 cursor、结束条件和跨页文件去重保护。
- 遇到重复 cursor 会安全停止，避免无限加载；续页请求失败后可重新触发。
- Box 与 Dropbox 的后台扫描跳过缩略图补全，降低大目录扫描的额外 API 请求。
- 阿里云盘全盘搜索的范围设置会传递备份盘、资源盘和相册对应的 drive ID。
- 不支持全盘搜索的网盘不再展示搜索入口；直接调用时会给出明确提示。

### 稳定性与体验修复

- 对阿里云盘目录扫描请求增加统一节流，降低 `TooManyRequests` 发生概率。
- 修复 123 云盘根目录及分页目录的文件/文件夹加载路径，避免仅显示首页项目或误提示找不到目录。
- 优化后台媒体获取任务的启动时机，避免与账号和网盘初始加载竞争资源。
- 系统文件关联调整为仅注册实际支持的书籍与漫画格式。

## English

### Startup and performance

- The main window is now shown first. Account refresh, transfer history, storage statistics, WebDAV, and update checks initialize in the background so a slow provider cannot block access to files.
- Upload and download workers are created on demand, while queued messages are delivered once the worker is ready.
- Heavy pages and preview components are lazy-loaded to reduce startup cost.
- Baidu Pan account and directory requests now have timeout protection, preventing a stalled account from blocking startup.

### Drive browsing, search, and pagination

- Infinite scrolling in the file list and video, music, and book scanning now share one pagination state machine: the same cursor handling, completion rules, and cross-page deduplication.
- Repeated cursors stop safely to prevent infinite loading, and a failed continuation request can be retried.
- Background Box and Dropbox scans skip thumbnail hydration to reduce extra API traffic in large folders.
- Aliyun Pan global-search scopes now pass the selected backup, resource, and album drive IDs.
- Providers without global search no longer show a search entry point and return a clear message if invoked directly.

### Stability and fixes

- Aliyun directory-scan requests use shared throttling to reduce `TooManyRequests` errors.
- Fixed 123 Pan root and paginated-folder loading so files and folders are not limited to the first page or reported as missing.
- Delayed media-acquisition background work to avoid competing with initial account and drive loading.
- System file associations now include only book and comic formats supported by the application.
