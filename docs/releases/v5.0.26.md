# BoxPlayer v5.0.26

## 中文

### 修复

- 修复正式发布包遗漏 PostHog 项目 Key 与 Host 的问题。此前打包流程会在构建阶段重新生成配置，并将遥测配置覆盖为空，导致正式用户不会上报事件。
- 为发布工作流新增回归测试，确保实际 Electron 打包步骤持续传入 PostHog 配置。

## English

### Fixes

- Fixed missing PostHog project key and host in release builds. The build step regenerated configuration and overwrote analytics settings with empty values, preventing production clients from sending events.
- Added a release-workflow regression test to ensure the actual Electron packaging step always receives PostHog configuration.
