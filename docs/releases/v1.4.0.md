# AlipanBuddy v1.4.0

一次彻底的瘦身，外加 Office / PDF 在线预览。功能面没有变小：砍掉的都是早已不存在的功能留下的骨架、
Electron 时代的兼容层，以及为了从未构建过的平台而携带的二进制文件。

## 新功能

- **Office 文档与 PDF 在线预览**。双击 doc / docx / xls / xlsx / ppt / pptx / wps / et / dps / pdf 等文件，
  会在预览窗口中打开阿里云盘自己的 WebOffice 预览器：先向 `v2/file/get_office_preview_url` 取预览地址与令牌，
  再按需从阿里 CDN 加载预览 SDK 并把令牌交给它；SDK 加载失败时退回为直接嵌入预览页。
  加密文件与违规文件会被拒绝并提示。首次打开需要能访问 `g.alicdn.com`。

## 架构

- **上传在主窗口运行**。隐藏的"上传进程"/"下载进程"窗口是 Electron 时代为了不卡住界面而设的；
  迁到 Tauri 后哈希与分片上传早已在 Rust 里完成，那两个隐藏 WebKit 进程（其中"下载进程"根本什么都不做）
  和它们之间的 JSON 消息总线、Map/Set 编解码、设置与令牌的重复同步全部移除。界面因此更跟手。
- **按功能组织代码**。上传相关代码此前分散在四个目录，现在 `src/upload/`、`src/download/` 各自拥有自己的
  队列、执行器、持久化与界面，`src/transfer/` 只剩传输页外壳。
- **只剩一套 UI 组件库**。ant-design-vue 之前仅为 Tooltip、Checkbox 和目录树保留，却占 91 MB 安装体积；
  三者全部换成 Arco。目录树的虚拟滚动、拖放、右键菜单行为保持不变，行高与缩进线略有差异。
- **渲染层 ↔ Rust 改为类型化调用**。`window.WebXxx` 这一整层 `any` 类型的全局函数被 `src/tauri/app.ts`
  里的具名函数取代，死掉的命令因此无处藏身：Rust 侧删掉了 6 个从未被调用的命令、一个未使用的插件和多余的
  权限授予。
- **列表 store 走一个工厂**。分享 / 订阅 / 传输共 10 个 store 逐字重复着同一套 20 个选择方法，
  现在由 `src/store/selectableList.ts` 生成，公开接口不变；5 个分享列表页也共用一个 `ShareListPage` 组件。
- **aria2 只有一个客户端**。此前四层封装并存，主逻辑还绕过类型化封装直接写 RPC 方法名字符串；
  现在一个传输层、一组类型化调用，批量操作走 `system.multicall`。
- **插件工具去重**。"重复文件清理"与"扫描重复文件"、"扫描空文件夹"与"空目录扫描"各是同一功能的两份实现，
  菜单里出现两次；保留新实现，三个扫描页共用一个脚手架。
- **Aria2 设置合并为一页**。"远程 Aria"和"下载高级设置"绑定着同一批设置项，现在是一页 "Aria2 引擎"。
- 剩余的多网盘抽象（永远返回 aliyun 的 provider 表、永真的 `isAliyunUser` 门控、只有一项的分享链接模式表）
  全部移除。

## 移除

- **macOS 构建暂时停止**：没有 CI、没有预编译包，却携带着 7.8 MB 的 darwin aria2c、签名配置和 Rust 分支。
  代码保持平台无关（用能力探测而不是平台判断），以便日后恢复。
- Windows ARM64 继续提供，但仓库里的"arm64 aria2c"与 x64 文件逐字节相同，现在明确复用 x64 二进制（模拟运行）。
- Linux 的 tar.gz 分发与 `install.sh` 移除，deb / rpm 保留（打包脚本本身的存在理由——避免与系统 aria2 冲突——不变）。
- `promote-release` 工作流与预发布门移除：打标签直接发布正式版。
- 每次构建自动递增版本号的脚本移除：版本号由手工提交决定，CI 从未用过它，而它曾意外把 1.1.0 升成 1.1.1。
- 未被任何地方引用的 `adrive sdk/` 文档、`static/images/`、重复图标、六份从未被读取的 `aria2.conf` 副本。

## 守护

为了不再重演，仓库加上了机械化的约束：`noUnusedLocals` / `noUnusedParameters`、`knip`（未使用的文件、导出与依赖，
CI 中零告警）、i18n 引用测试（每个键都必须在代码中出现，两种语言键集合一致）、推送与 PR 触发的 CI 工作流，
以及 `pnpm run metrics` 输出上表中的数字。CLAUDE.md 记录了"每个关切只有一种做法"及其原因、删除功能时的清单、
过渡代码的过期规则和发布后的例行瘦身。
