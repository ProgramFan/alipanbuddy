## BoxPlayer v5.0.16

### 媒体服务器播放 / Media Server Playback

- 媒体服务器遇到浏览器不支持的音频编码（例如 AC-3、E-AC-3、DTS、TrueHD）时，会优先请求兼容转码播放，避免只有画面没有声音。
- 若服务器无法提供转码地址，会自动回退到原始直连播放，不会因兼容模式导致文件完全无法播放。
- Jellyfin、Emby 与 Plex 的外挂字幕会作为可选字幕源加载到网页播放器和内嵌 MPV；仅在可转码并可切换轨道时展示音轨、字幕轨道选择器。
- Emby 播放请求补充兼容的 User-Agent，并修复内嵌 MPV 自定义请求头中逗号、反斜杠未转义导致的加载失败。

### 字幕与界面 / Subtitles & UI

- 修复网页播放器切换外挂字幕后暂停状态下不刷新当前字幕的问题。
- 新增 UTF-16 LE/BE（含无 BOM）字幕识别，避免部分 SRT、ASS 字幕显示乱码。
- Box 网盘“最近文件”虚拟目录现在可正确解析和打开；其他网盘不再错误显示不支持的“最近文件”入口。

### English

- Media-server playback now requests compatible transcoding for browser-unsupported audio codecs, while falling back to the original stream when the server cannot provide a transcode URL.
- External subtitle sources from Jellyfin, Emby, and Plex are available in the web player and embedded MPV. Audio/subtitle track controls appear only when the selected playback stream supports switching.
- Fixed embedded MPV request-header escaping and subtitle refresh after changing external subtitles. UTF-16 LE/BE subtitle files, including files without a BOM, now decode correctly.
- Fixed Box Recent Files virtual-directory resolution and hid unsupported Recent Files entries from other providers.
